# Фабрика генераторов КП: как завести нового клиента

Один общий код, у каждого клиента своя папка с данными. Боним – клиент №1 (`clients/bonim/`).

## Что где лежит

| Что | Где |
|---|---|
| Общий код генератора | `src/` |
| Данные клиента (тексты, цвета, системы, реквизиты) | `clients/<id>/client.json` |
| Картинки клиента (логотипы, фото обложки и систем) | `clients/<id>/img/` |
| Данные для Сделки Kommo и для Агента | `clients/<id>/deal_fields.json` |
| Шаблон брифа клиента (Excel) | `clients/_template/Бриф_клиента_шаблон.xlsx` |
| Скрипты | `scripts/` |

## Шаги для нового клиента

1. **Бриф.** Скопировать шаблон брифа, заполнить вместе с клиентом (жёлтые клетки). Пустые обязательные поля скрипт не пропустит.
2. **Данные клиента.**
   `python scripts/brief_to_client.py "Бриф_клиента_<имя>.xlsx"`
   Создаётся `clients/<id>/client.json` и `deal_fields.json`.
3. **Картинки.** Положить файлы, названные в брифе, в `clients/<id>/img/`. Только настоящие фото. Логотипы: PNG с прозрачным фоном, одна версия для светлого фона, одна для тёмного.
4. **Сборка.** `npm run build:client -- <id>`. Готовые файлы появятся в `dist-clients/<id>/`.
5. **Адрес.** Загрузить содержимое папки на хостинг в `public_html/cp/<id>/` (адрес `cp.newformatai.com/<id>/`).
6. **Проверка глазами**: русская и ивритская версии, 4 страницы, телефон. Потом показать менеджеру.
7. **Сделка в Kommo**: завести по данным из `deal_fields.json` (воронка «Генераторы КП», срок «оплачено до»).

## Правила

- Тире только короткое «–». Шрифт не меньше 11-12pt. Логотип только настоящий файл, никогда не генерируется.
- Цены вводит менеджер без НДС, 18% добавляется сам (процент берётся из брифа).
- Не выкладывать в GitHub ключи, пароли и `.env`.
